# Robot Push Lab V10

- Force moteur joueur par défaut : 100 N.
- Deux roues motrices arrière avec conduite différentielle.
- Deux points de contact avant passifs, à faible adhérence.
- Rotation rapide sur place.
- Frein au relâchement conservé.
- Bouton R pour remettre le robot droit.
- Caméra isométrique qui suit doucement le robot sans tourner avec lui.
- Version destinée en priorité à l'ordinateur : ZQSD, R, N et C.
- Page Options physiques conservée.
