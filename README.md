# Robot Push Lab V15

## Version 15
- Configuration par défaut mise à jour depuis l'export utilisateur du 17 novembre 2026.
- Configuration unique du robot partagée entre laboratoire, test IA et hockey.
- Vitesse maximale, accélération maximale et décélération au freinage réglables dans les paramètres.

## Sections séparées
- Laboratoire et tests : test manuel, test IA, palets multiples, diagnostic et options physiques.
- Mode Hockey : bouton et page de paramètres dédiés.

## Hockey paramétrable
Terrain (largeur, longueur, murs), buts (largeur, profondeur, hauteur), match (durée, score gagnant, délai), palet (diamètre, hauteur, masse, rebond, glissement), robot (vitesse maximale, accélération, décélération, force moteur, rotation et freinage) et caméra (hauteur, décalage).

Le mode Hockey utilise un seul palet central, deux buts, un score et un chronomètre. Le laboratoire conserve ses propres palets et obstacles.
